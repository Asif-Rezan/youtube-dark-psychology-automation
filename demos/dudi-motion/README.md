# Dudi Dam motion review

Source: scene-000-source.png from successful production run 41254581826.
The built-in ImageGen tool extracted the rabbit (correcting the original extra ear)
and filled its old location to produce a clean garden plate. Prompts: preserve the
exact Dudi Dam 3D storybook rendering, isolate the same full-body rabbit with true
alpha transparency; remove only the rabbit and complete the original garden path.
Original, derived background and rabbit artwork are in assets/.

GitHub Actions performs the CPU animation and combines it with the original rhyme
audio. Ear/tail mesh motion, body breathing, hops and landing squash are puppet
animation, not generated 3D video. This standalone demo never uploads to YouTube
or Facebook and does not change production scheduling or rendering.
