YoutubeAutomation privacy policy

Last updated: November 3, 2026

YoutubeAutomation is operated by Asif Rezan for the Grow with Rezan YouTube channel. It is an owner-operated video creation and upload workflow, not a public service with user accounts.

Google data accessed

With the operator's Google authorization, the workflow reads the selected YouTube channel's identity and video information, uploads videos and metadata to that channel, and accesses files in an app-authorized Google Drive folder used for video production. The requested permissions are YouTube read and upload access and Google Drive access limited to files used with this app.

Use and storage

The workflow uses this information only to prepare, store, upload, and verify the operator's videos. OAuth credentials are stored as encrypted GitHub Actions secrets. Production files and checkpoints are stored in the operator's Google Drive. Lyrics, music and illustrations are generated with local models on GitHub Actions CPU runners. Public model files are downloaded from Hugging Face. Google OAuth credentials are sent only to Google APIs.

Sharing and retention

Google data is not sold or used for advertising. It is shared only with the services needed to run this workflow, including Google Drive, YouTube, and GitHub Actions. The new kids pipeline uses an isolated private Drive subfolder. Temporary media is removed after verified public HD publication; compact history and upload checkpoints are retained. The operator may explicitly request cleanup of older production files. Generated media may also be retained as GitHub artifacts for seven days. The operator can revoke the app's Google access and delete stored credentials and files at any time.
