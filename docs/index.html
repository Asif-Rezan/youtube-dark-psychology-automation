YoutubeAutomation

YoutubeAutomation is an owner-operated tool that prepares videos and uploads them to the Grow with Rezan YouTube channel. It uses Google authorization to read the selected YouTube channel, upload videos privately, and work with files in an app-authorized Google Drive folder.

There is no public sign-up or service for other users. The operator controls each authorization and can revoke it in their Google Account.
